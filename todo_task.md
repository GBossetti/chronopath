Database Security Options                                                                                                                                                                                        
                                                                                                                                                                                                                   
  1. SQLCipher (Recommended)                                                                                                                                                                                       
                                                                                                                                                                                                                   
  Full database encryption using AES-256. The entire .db file is encrypted at rest.                                                                                                                                
                                                                                                                                                                                                                   
  - Pros: Industry standard, transparent to Room queries, protects against file extraction                                                                                                                         
  - Cons: Slight performance overhead, ~3MB added to APK size                                                                                                                                                      
  - Library: net.zetetic:android-database-sqlcipher                                                                                                                                                                
                                                                                                                                                                                                                   
  2. Key Management Options (for SQLCipher)                                                                                                                                                                        
  ┌──────────────────┬─────────────────────────────────────┬───────────────────────────────┐                                                                                                                       
  │     Approach     │              Security               │              UX               │                                                                                                                       
  ├──────────────────┼─────────────────────────────────────┼───────────────────────────────┤                                                                                                                       
  │ User passphrase  │ Highest - only user knows it        │ Must enter on each app launch │                                                                                                                       
  ├──────────────────┼─────────────────────────────────────┼───────────────────────────────┤                                                                                                                       
  │ Android Keystore │ High - hardware-backed, device-tied │ Seamless, automatic           │                                                                                                                       
  ├──────────────────┼─────────────────────────────────────┼───────────────────────────────┤                                                                                                                       
  │ PIN + Keystore   │ High - combines both                │ Enter PIN once per session    │                                                                                                                       
  └──────────────────┴─────────────────────────────────────┴───────────────────────────────┘                                                                                                                       
  3. What Won't Work                                                                                                                                                                                               
                                                                                                                                                                                                                   
  - Hashing: One-way function - you couldn't read your location data back                                                                                                                                          
  - User/pass alone: Only protects UI access, not the database file itself                                                                                                                                         
                                                                                                                                                                                                                   
  My Recommendation                                                                                                                                                                                                
                                                                                                                                                                                                                   
  SQLCipher + Android Keystore for this app because:                                                                                                                                                               
  1. Location data is personal/sensitive                                                                                                                                                                           
  2. Encryption is transparent to your existing Room code                                                                                                                                                          
  3. No password to remember - key is hardware-backed                                                                                                                                                              
  4. Protects against someone extracting the database file from the device                                                                                                                                         
                                                                                                                                                                                                                   
  If you want extra protection, we can add a PIN/biometric unlock that gates access to the Keystore key.                                                                                                           
                                                                                                                                                                                                                   
  Which approach would you like to implement?                                                                                                                                                                      
                                                                                                                                                                                                                   
❯ Explain each of the 4 points                                                                                                                                                                                     
                                                                                                                                                                                                                   
● 1. Location data is personal/sensitive                                                                                                                                                                           
                                                                                                                                                                                                                   
  Your app stores a continuous history of where the user has been - home address, workplace, frequented locations, travel patterns. This is highly sensitive personal data that could be misused for:              
  - Stalking or tracking someone's movements                                                                                                                                                                       
  - Burglary (knowing when someone is away from home)                                                                                                                                                              
  - Profiling daily routines                                                                                                                                                                                       
                                                                                                                                                                                                                   
  Without encryption, anyone with physical access to the device (or a backup) could simply copy the .db file and open it with any SQLite viewer to see all locations.                                              
                                                                                                                                                                                                                   
  ---                                                                                                                                                                                                              
  2. Encryption is transparent to your existing Room code                                                                                                                                                          
                                                                                                                                                                                                                   
  SQLCipher is a drop-in replacement for SQLite. Your existing code:                                                                                                                                               
                                                                                                                                                                                                                   
  Room.databaseBuilder(context, LocationDatabase::class.java, "locations.db")                                                                                                                                      
      .build()                                                                                                                                                                                                     
                                                                                                                                                                                                                   
  Becomes:                                                                                                                                                                                                         
                                                                                                                                                                                                                   
  val passphrase = getKeyFromKeystore()                                                                                                                                                                            
  val factory = SupportFactory(passphrase)                                                                                                                                                                         
                                                                                                                                                                                                                   
  Room.databaseBuilder(context, LocationDatabase::class.java, "locations.db")                                                                                                                                      
      .openHelperFactory(factory)  // <-- only addition                                                                                                                                                            
      .build()                                                                                                                                                                                                     
                                                                                                                                                                                                                   
  All your DAOs, queries, entities, and repository code remain unchanged. The encryption/decryption happens automatically at the database driver level.                                                            
                                                                                                                                                                                                                   
  ---                                                                                                                                                                                                              
  3. No password to remember - key is hardware-backed                                                                                                                                                              
                                                                                                                                                                                                                   
  The Android Keystore stores cryptographic keys in a secure hardware module (TEE or StrongBox on newer devices). Benefits:                                                                                        
                                                                                                                                                                                                                   
  - Keys never leave the hardware - even if the OS is compromised, the key material cannot be extracted                                                                                                            
  - Automatic unlocking - once the device is unlocked, your app can use the key without user interaction                                                                                                           
  - Tied to device - the key cannot be backed up or transferred, so a stolen database file is useless on another device                                                                                            
                                                                                                                                                                                                                   
  The user experience is seamless - no passwords or PINs required on each launch.                                                                                                                                  
                                                                                                                                                                                                                   
  ---                                                                                                                                                                                                              
  4. Protects against someone extracting the database file                                                                                                                                                         
                                                                                                                                                                                                                   
  Without encryption, an attacker could access your database through:                                                                                                                                              
  - ADB backup (if enabled)                                                                                                                                                                                        
  - Rooted device - direct file system access to /data/data/com.chronopath.locationtracker/databases/                                                                                                              
  - Device backup extraction - from cloud or local backups                                                                                                                                                         
  - Physical access - stolen/lost device                                                                                                                                                                           
                                                                                                                                                                                                                   
  With SQLCipher + Keystore:                                                                                                                                                                                       
  - The .db file is AES-256 encrypted gibberish without the key                                                                                                                                                    
  - The key exists only in that device's secure hardware                                                                                                                                                           
  - Even with root access, the database contents are unreadable without the Keystore key
